# 字体差异清单（规范一.3：替换前须用户确认）

> 状态说明：本清单列出 PDF 中出现的全部字体、Web 可获得性与授权情况、拟用 Web 方案、以及与 PDF 原字的差异点。
> **在你逐项确认之前，页面暂用系统字体兜底，不做任何正式替换。**
> 确认方式：直接回复每项「同意 / 换方案 / 保持系统兜底」即可。

---

## 1. 汉仪旗黑（HYQiHei）— 中文正文/标题主字体

| 项 | 内容 |
|---|---|
| PDF 用途 | 全站中文正文、标题、导航、联系方式（出现频率最高） |
| Web 可用性 | ❌ 商业授权字体，不能自托管到 GitHub Pages（公开仓库 = 公开分发，侵权） |
| 拟用方案 | **思源黑体 Noto Sans SC**（Google Fonts / 自托管 woff2，SIL 开源授权，可免费商用） |
| 差异点 | 笔画骨架接近，同字重下旗黑略「瘦硬」，思源黑略「圆润」；字号相同时思源黑实际占宽略大 1–2%，字距/换行位置可能有细微差别 |
| 备选 | 阿里巴巴普惠体（同为免费商用，间架更接近旗黑的黑体感） |

## 2. Alissan — 章头巨号装饰英文字（474px）

| 项 | 内容 |
|---|---|
| PDF 用途 | 各章头超大英文（TINGZONG / KV 等）、"2025" 水印 |
| Web 可用性 | ❌ 商业字体，无法自托管 |
| 拟用方案 | **Jost**（Google Fonts，OFL 开源）——几何无衬线，大字号下气质接近 |
| 差异点 | Alissan 的个别字母（如 G、S）带独特切角造型，Jost 无此细节；字面略窄，需按 PDF 逐字校对字距（letter-spacing） |
| 备选 | 若对章头造型要求极高，可把章头大字做成 **SVG 矢量图**（从 PDF 轮廓转出，视觉 100% 一致，代价是不可后台改文案——章头英文极少改动，通常可接受） |

## 3. Champignon — 花体手写英文

| 项 | 内容 |
|---|---|
| PDF 用途 | CONTACT 首字母 C、PORTFOLIO DESIGN 水印等花体装饰 |
| Web 可用性 | ⚠️ Champignon 本身在 Google Fonts 有（OFL 授权，可合法自托管） |
| 拟用方案 | **Champignon 原字体自托管**（woff2，视觉零差异） |
| 差异点 | 无（原字体可用） |
| 现状 | 沙箱网络取不到 Google Fonts，当前用 cursive 系统兜底；上线前把 woff2 下载进仓库即可 |

## 4. Times New Roman Italic — 英文诗句/斜体衬线

| 项 | 内容 |
|---|---|
| PDF 用途 | 英文小诗、斜体点缀 |
| Web 可用性 | ✅ 系统字体（Windows/macOS/多数设备内置），Web 使用无授权问题 |
| 拟用方案 | **原字体直接用**：`font-family: "Times New Roman", Times, serif; font-style: italic` |
| 差异点 | 无（原字体可用）；仅极少数安卓设备无此字体，会退到系统衬线体，视觉接近 |

## 5. 方正字迹-朱子明行书（诗句/明朝体风格装饰中文）

| 项 | 内容 |
|---|---|
| PDF 用途 | 诗句印章卡上的书法风中文 |
| Web 可用性 | ❌ 方正商业授权，不能自托管 |
| 拟用方案 | **这部分文字已随诗句卡整卡切图**（images/v2/p02_poem_1~4.webp），卡内书法字不在网页文字流里，无需字体替换 |
| 差异点 | 无（切图即原样）；代价是该部分文字后台不可改（诗句卡内容固定） |

## 6. 阿里巴巴普惠体（AlibabaPuHuiTi）— 联系区

| 项 | 内容 |
|---|---|
| PDF 用途 | p01 联系方式区域 |
| Web 可用性 | ✅ 阿里普惠体 2.0 官方允许**免费商用含 Web 嵌入**，可自托管 |
| 拟用方案 | **原字体自托管**（从阿里官方渠道下载 woff2 进仓库），或与正文统一用思源黑体减少加载量 |
| 差异点 | 原字体=零差异；若统一到思源黑体，联系区字形与 PDF 有第 1 项所述的细微差异 |

## 汇总：需要你拍板的 3 个决定

1. **中文主字体**：思源黑体（推荐）还是阿里巴巴普惠体（全站统一用它，与联系区原字体一致）？
2. **章头巨号英文 Alissan**：Jost 字体近似（文字可后台改）还是 SVG 轮廓切图（视觉 100% 还原，文案写死）？
3. **花体 Champignon + 普惠体**：确认上线前由我把对应 woff2 文件下载进仓库自托管（需网络可达时执行）。

> 以上任何一项你未确认前，页面保持系统字体兜底状态，不会擅自替换。
