# 部署与后台说明（GitHub Pages + Sanity CMS）

> 你的分工只有两件事：**push 代码** 和 **在 Sanity 后台点「发布」**。其余全部由 AI 完成。

---

## 一、日常上线流程（改了网页代码/图片后）

在**本机 PowerShell**（不是 WorkBuddy）执行：

```powershell
cd D:\portfolio-web
git add -A
git commit -m "更新"
git push origin main
```

- push 需要先开**本地代理软件**（127.0.0.1:11304），git 已配置走该代理；代理没开会 push 失败。
- push 后 GitHub Pages 约 **1~2 分钟** 生效，浏览器 Ctrl+F5 强刷。
- 线上地址：https://392027594-del.github.io/lijinshan.github.io
- 注意：`index.html`、`styles.css`、`data.js`、`images/` 任何改动都要 push；只改 Sanity 后台内容**不需要** push。

## 二、后台改内容（Sanity CMS，不动代码）

1. 双击 `D:\portfolio-studio\start-studio.bat` 启动后台（或已设开机自启）。
2. 浏览器打开 `http://localhost:3333`。
3. 可改内容：
   - **站点信息**：姓名、手机、微信、邮箱、导航文字
   - **板块标题**：各章头标题/编号/说明文字
   - **作品**：每个作品可隐藏/排序；每个图片槽位可换图、改 alt、改焦点（focus）
   - 图片槽位编号见《图片槽位表.md》，后台按顺序与页面槽位一一对应
4. 改完点右上角**「发布」**，约 1 分钟线上生效。
5. 后台挂掉也不影响网站：`data.js` 拉取失败会自动回退到本地图片和文字，**不会白屏**。

### 后台改图规则（重要）

- 每个槽位**锁定了宽高比例**，换图只会在槽内裁切，版式不会跑。
- `object-fit: cover` 统一裁切填满；若主体被裁到，调该槽位的 focus（如 `50% 30%`）把焦点移上去。

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| push 卡住/超时 | 代理软件没开 | 先开代理再 push |
| 线上没变化 | 浏览器缓存 | Ctrl+F5 强刷 |
| 后台新加的字段看不见 | Studio 未重启 | 关掉 bat 窗口重新双击 |
| 图片裂图 | 本地图片文件缺失 | 检查 `images/v2/` 对应文件名 |
